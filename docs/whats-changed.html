The report is published, with a list of 481 parks

September 15, 2026

Tags: Site, Data

In answer to a request from New Yorkers for Parks, the report lists NYC parks that appear to let cars drive through them: every park that contains a road segment cars can use, except Central Park and Prospect Park. It finds 481 of 2,059 parks, and says the list includes some parks that do not belong and needs to be checked by hand. The list can be downloaded as a spreadsheet (CSV) and as a map file (GeoJSON). Wording edits and a source note for the City's street map data followed the same day.
