# What's changed

This page lists the changes to the report Identifying NYC Parks with Vehicle Traffic that a reader would notice, newest first, including corrections when we published something wrong.

- **History begins:** 2026-09-15, the day the report was first published. Dates are the day each version went up on the site, in New York time. Corrections made before this date may be missing.
- **Data refresh:** none. The list of parks comes from NYC Open Data as it stood when the report was last built, and it does not update on its own.

To report a bug in the report, or to ask for a new feature, [open an issue on GitHub](https://github.com/BetaNYC/roads-in-nyc-parks/issues).

## 2026-11-12: A page that lists what changed in the report

- **Tags:** Site
- **What changed:** This page is new. It lists each version of the report and any correction, newest first. The report links to it from its footer the next time the report is rebuilt.
- **More detail:** [The file this page is built from](https://github.com/BetaNYC/roads-in-nyc-parks/blob/main/WHATS-CHANGED.md)

## 2026-09-15: The report is published, with a list of 481 parks

- **Tags:** Site, Data
- **What changed:** In answer to a request from New Yorkers for Parks, the report lists NYC parks that appear to let cars drive through them: every park that contains a road segment cars can use, except Central Park and Prospect Park. It finds 481 of 2,059 parks, and says the list includes some parks that do not belong and needs to be checked by hand. The list can be downloaded as a spreadsheet (CSV) and as a map file (GeoJSON). Wording edits and a source note for the City's street map data followed the same day.
- **More detail:** [The commit](https://github.com/BetaNYC/roads-in-nyc-parks/commit/1f10560) · [Same-day edits](https://github.com/BetaNYC/roads-in-nyc-parks/commits/main/?since=2026-09-15&until=2026-09-16)
